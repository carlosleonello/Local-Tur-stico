Local turístico — Busan

Projeto desenvolvido como parte de um desafio proposto no curso Full Stack da Rocketseat, com o objetivo de praticar os fundamentos de HTML e CSS a partir de um layout de referência.

A página apresenta a cidade de Busan, na Coreia do Sul, destacando suas paisagens, sua história e três destinos turísticos.

Tecnologias utilizadas:
HTML5
CSS3

Google Fonts: Open Sans

Sobre a página:
O conteúdo reúne uma apresentação de Busan e informações sobre os seguintes locais:
Templo Haedong Yonggungsa: templo budista localizado à beira-mar.
Templo Beomeo-sa: santuário cercado pelas montanhas da cidade.
Parque Yongdusan: parque que abriga a Torre de Busan e outras atrações culturais.
Cada destino conta com imagem, descrição e indicações de público ou interesse.

Aprendizados:
Durante o desenvolvimento, foram praticados:
Estruturação de uma página com HTML.
Organização de títulos, parágrafos, listas e seções.
Estilização com classes e seletores CSS.
Aplicação de fontes, cores e espaçamentos.
Ajuste do tamanho e alinhamento de imagens.

Como visualizar:
Baixe ou clone este repositório.
Abra a pasta do projeto.
Abra o arquivo index.html no navegador.
